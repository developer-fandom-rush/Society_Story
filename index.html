How to add an episode manually in GitHub Show steps

Updating the EXISTING Episode 01 story: Open content/STORY.md, click the pencil icon, find # Society Wives — Episode 1 — Story (Grok + GPT Inserts), and edit/replace its reading prose with your approved Episode 01 text. Keep only one Episode 01 story heading. Then Commit changes to main and wait for Pages.

Publishing a NEW finalized episode (Episode 02 or later):

  1. Open content/STORY.md on GitHub and sign in.
  2. Click the pencil / Edit this file icon. You may need to open the ⋯ menu first.
  3. Scroll to the end. Paste the finished episode below the current episode, with a new # heading:
# Society Wives — Episode 02 — Story

## Ankita
Paste finalized Ankita prose here.

## Shivani
Paste finalized Shivani prose here.

## Shreya
Paste finalized Shreya prose here.

## Taniya
Paste finalized Taniya prose here.

## Meenakshi
Paste finalized Meenakshi prose here.
  1. Click Commit changes and save to the main branch (or open a pull request and merge it).
  2. Wait for GitHub Pages deployment to finish, then refresh the Actual Story tab.

Editing a prompt instead? Open content/PROMPTS.md, use the same pencil → edit → commit steps, and refresh Writing Prompts. To create a new Master Pack, start it with a new # Society Wives — Episode 05 Master Pack heading.

Important: One # creates a chapter. Use ## for scenes/characters and ### for smaller parts. Don't paste Master Pack prompts into the Story file. Editing Google Docs alone does not update GitHub.
